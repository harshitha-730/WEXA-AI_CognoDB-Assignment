# WEXA-AI CognoDB Benchmark Assignment

This repository contains the Graph DB Benchmark project inside the `graph-db-benchmark/` folder.

## Project contents

- `graph-db-benchmark/` - main benchmark project directory.
- `graph-db-benchmark/README.md` - full setup, execution, and analysis instructions.
- `graph-db-benchmark/ASSIGNMENT_REPORT.md` - benchmark summary and observations.

## How to use this repository

1. Open the `graph-db-benchmark/` folder.
2. Follow the instructions in `graph-db-benchmark/README.md`.

## Notes

- The detailed benchmark code, data loading scripts, and plots are all inside `graph-db-benchmark/`.
- If you want to review the results and observations, start with `graph-db-benchmark/ASSIGNMENT_REPORT.md`.
